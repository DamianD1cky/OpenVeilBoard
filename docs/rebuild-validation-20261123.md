# VeilBoard 重构实施与验收

2026-11-23 · OpenVeilBoard 2.0

以 `branch/veilboard` 的 WebGPU 台面重建 SPA，接入 `branch/Hamburger_Protect` 的账号、角色、房间权限和服务端投骰。旧工作副本已在本机备份，两份参考工程保持原样。

## 实施结果

| 阶段 | 已接入 |
|---|---|
| 底座与账号 | Vite SPA、React 19 浮层、WebGPU 暗房开屏、最近房间恢复、账号与审批接口。旧作品集页面、视频、Lab 场景和办公室已移出。 |
| 便签与归档 | 四种中文纸卡、封面和 Markdown、打印落桌、骨骼拖拽、Hover 速览、归档检索与取回；新建和取回时优先选择空位。 |
| 便签能力 | 清单、事件钟、检定、批注、保密、物资、标签。台面最多三个角标，机密字段由数据库隔离，保存按字段检查冲突。 |
| 物理红线 | 便签端点、悬停高亮、样式与纸签、归档恢复；实时刷新保留待保存修改。休眠后不采样端点、不上传顶点。 |
| 时钟、骰子与降级 | 印漆战役历法、正计时和倒计时；七种实体骰、成签和共享结果；无 WebGPU 时使用同一数据源的 2D 台面。 |

## 验证结果

| 检查 | 结果 |
|---|---|
| `npm run build` | 类型检查、生产构建通过。仍有包体大小和骰子库浏览器兼容提示，浏览器投骰用例通过。 |
| `npm test` | 11 项通过，覆盖坐标兼容、空位选择、归档连线、乐观合并、并发冲突和数据库权限。 |
| `npm run check:browser` | 1440×900、390×844 共 5 组用例通过，无报告的页面错误。覆盖账号接口夹具、便签编辑、连线、归档、走时、投骰和刷新恢复。 |
| WebGPU 性能 | 本机 Chrome 无头测试稳态采样约 60 fps；红线休眠后端点采样和顶点上传计数无增长。 |
| Supabase 生产库 | 已应用 `20261123000000_veilboard_surface.sql`；迁移前后均为 3 个房间、6 个成员、7 张便签。4 张订阅表已启用，匿名账号不可执行公告板读取 RPC，已登录账号不可直读私有便签表。 |

真实后端使用 `notes`、`note_links`、`campaign_settings.clock_config` 和 `dice_rolls`。迁移保留旧版像素坐标，与新版归一化坐标双向换算。投骰结果以服务端为准，不同设备的动画轨迹允许有差异。

本机入口为 `http://127.0.0.1:5188/`，演示入口为 `/?demo=1`，强制 2D 为 `/?demo=1&fallback=1`。本机投骰由 Vite 转发当前用户 JWT，服务端仍校验成员身份。

登录浏览器测试使用 Auth/RPC 夹具；真实账号注册与双账号联机、Safari、120 Hz 和高密度台面尚未实测。此记录不代表前端已部署上线。
